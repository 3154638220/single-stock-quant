## 一、战略转向：为什么回归单股

### 1.1 八轮实验的核心教训

八轮迭代的最终结论只有一句话：**整个轮动框架的真实 alpha 来源只有 300750（宁德时代）一只股票**。其余 6 只"防御股"在去除 300750 后年化仅 3.27%。

轮动框架带来的不是 alpha 分散，而是**复杂度税**：

| 问题 | 代价 |
|---|---|
| 7 只股票的选股逻辑、board 约束、板块约束 | 代码复杂度翻倍，参数空间爆炸 |
| H-dual+dd exit 对 A 股 V 型反转过于保守 | 2019/2020 牛市踏空 100pp+ |
| per-symbol 参数与全局参数的 T4 悖论 | 修复 T4 则年化从 31% 跌至 11% |
| 研究成果无法直接生产落地 | 8 轮迭代后仍靠人工操作 |

**单股策略的对比优势**：

- **已有实证**：300750 单股 WFO OOS（2020–2026）已实现 Ann 15.3%、Calmar 0.94，**没有经过任何信号深度优化**
- **可解释性强**：一只股票的信号、持仓、止损逻辑一目了然，参数搜索空间远小于轮动
- **生产落地直接**：单股信号 → 当日收盘判断 → 次日开盘执行，比轮动调仓简单 10 倍
- **目标明确**：任意指定一只股票，给出年化 ≥ 30%、Calmar ≥ 2.0 的策略

### 1.2 一个被忽视的关键数据点

在所有归档实验中，`configs/research/000783_best_return.yaml` 记录了一个结果：

```
东方财富基金（000783）
信号：eastmoney_dkbar（DKTrend）
止损：ATR trailing 2.5x + intrapos_dd 0.05
OOS 结果：Ann 13.86%，MDD 10.45%，Calmar 1.33，仅 7 笔交易
```

这是代码库中 **Calmar 最高的单股结果**，比 R7 轮动框架（Calmar 1.10）还高，且 MDD 只有 10.45%。

核心原因：**大趋势持有（ATR trailing 让盈利充分奔跑）+ 小波动快退（intrapos_dd 5% 快速止损）** 的组合，在趋势性强的标的上效果极好。这正是 300750 这类高 beta 趋势股的特性。

**第九轮的核心假设**：将该组合（DKTrend + ATR trailing + intrapos_dd）系统性地应用到 300750 及其他高趋势性标的，并通过 WFO 严格验证，可以实现 Calmar ≥ 2.0 的目标。

## 三、问题根因的深度分析

### 3.1 300750 当前策略的性能上界在哪里

当前 WFO OOS 结果（2020–2026，MACD 10,26,8）：

```
Ann 15.3%，Sharpe 0.93，MDD 16.4%，Calmar 0.94，54 笔交易，胜率 53.7%
```

**三个制约因素**：

**① 信号过早入场**：MACD cross 在趋势确认前就入场（MACD 柱翻正即买），平均持仓期较短（~15 天），大量交易在微弱信号时进出，手续费侵蚀严重。

**② 出场留下了大量利润**：profit_lock 8%/4% 在 300750 的大趋势中（2020 年涨 200%、2021 年 Q1 涨 80%）严重过早锁定。应用 ATR trailing 2.5x 可以显著延长优质交易的持仓时间。

**③ 熊市没有真正的防御**：T4（2022）：300750 单股用当前参数 OOS 结果未测（全周期只从 2020 起），需要 2018–2026 完整测试。2022 年 300750 从最高点跌 73%，即使有 stop_loss 8%，在频繁交易中可能有多次入场亏损。

### 3.2 信号工程的未被探索空间

当前代码库有三套独立信号系统，但从未系统性对比过它们在不同标的上的适配性：

| 信号类型 | 逻辑 | 适合标的特征 |
|---|---|---|
| DKTrend（eastmoney_dkbar） | 短周期均价 + 斜率 + 持续时间，趋势确认较慢 | 低噪声、趋势性强的股票 |
| MACD cross | MACD 柱翻正/负，反应较快 | 中等波动、趋势转折明显 |
| Donchian 突破 | 价格突破 N 日最高/最低 | 突破后有持续动能的股票 |

**R8 实验的关键发现**（经常被忽略）：000783 用 DKTrend + ATR trailing 实现 Calmar 1.33，而同期 300750 用 MACD + profit_lock 只有 Calmar 0.94。

**假设**：对于 300750 这样的高 beta 趋势股，DKTrend 的趋势确认慢的特性在牛市中减少了假信号，ATR trailing 让大趋势充分奔跑，组合效果优于 MACD + profit_lock。

### 3.3 持仓管理的核心矛盾

当前系统存在根本性的参数不协调：

```
profit_lock_trigger = 8%，profit_lock_trailing = 4%
```

这意味着：一旦涨了 8%，只要回撤 4% 就退出。对于 300750（日内波动 3–5%），这等同于"凡是涨了 8% 的交易，几乎注定会在 1–2 个波动日内被 profit_lock 踢出"。

**正确的参数体系**应基于标的的 ATR：

```python
# 对于 ATR/price ≈ 3% 的 300750：
atr_trailing_mult = 2.5   # 止损宽度 = 2.5 × ATR ≈ 7.5%
atr_trailing_min_gain = 0.10  # 先涨 10% 才激活（避免震荡）
intrapos_dd_limit = 0.05  # 持仓内最大回撤 5%（快速止损信号反转）
# 完全删除 profit_lock（让 ATR trailing 代替）
```

## 七、Phase S3：持仓管理升级

**目的**：解决当前策略"利润奔跑不够（profit_lock 过早）+ 亏损止损不够快（hard stop 一刀切）"的双重问题。

### S3-A：ATR Trailing Stop 系统性测试

这是本轮最高优先级的实验。基于 000783 的 Calmar 1.33 结论，以及 300750 的高 beta 趋势特性：

**核心逻辑**：
- 入场后，设置 `entry_price × (1 - stop_loss_pct)` 为初始硬止损（保底）
- 当持仓盈利超过 `atr_trailing_min_gain`，激活 ATR trailing
- ATR trailing 止损线 = 最高收盘价 - `atr_trailing_mult × ATR`
- `intrapos_dd_limit`：当日回撤超过 X%（从持仓最高点计），也触发平仓

**参数联动关系（300750 ATR ≈ 3% × close price）**：

```
场景 1：小亏损快出（硬止损）
  stop_loss_pct = 0.08
  → 最大单笔亏损 8%

场景 2：中等盈利正常跟踪
  atr_trailing_min_gain = 0.10  （涨了 10% 才激活）
  atr_trailing_mult = 2.5       （止损线 = 最高价 - 2.5×ATR ≈ 7.5%）

场景 3：大趋势充分奔跑
  不设 profit_lock（删除），让 ATR trailing 自然退出
  → 2020 年 300750 涨 200% 期间，ATR trailing 追着走，理论收益 100–150%

场景 4：持仓内震荡反转快速退出
  intrapos_dd_limit = 0.05      （持仓最高点回撤 5% 强制退出）
  → 避免"涨了 30% 又回撤 20%" 的深度回吐
```

**测试矩阵 S3-A**（在 300750 全周期）：

| 配置 | stop_loss | atr_mult | atr_min_gain | intrapos_dd | profit_lock |
|---|---|---|---|---|---|
| S3-A1（当前基线） | 8% | 0 | 0 | 0 | 8%/4% |
| S3-A2（ATR trailing） | 8% | 2.5 | 10% | 0 | 关 |
| S3-A3（ATR + intrapos） | 8% | 2.5 | 10% | 5% | 关 |
| S3-A4（ATR 宽松） | 8% | 3.0 | 12% | 6% | 关 |
| S3-A5（ATR 严格） | 7% | 2.0 | 8% | 4% | 关 |

**S3-A 验收**：在 T3（牛市）中 S3-A 系列配置 Ann ≥ S3-A1 × 1.3（ATR trailing 让牛市利润更大），在 T4（熊市）中 MDD ≤ S3-A1（stop_loss 保底不变）。

### S3-B：市场 Regime 门控（单股专用版）

轮动框架的 H-dual+dd（MA60+MA120+DD15%）被证明对 A 股 V 型反转**过于保守**（2019 年踏空 55pp）。单股策略需要更精细的 regime 门控。

**重新设计思路**：单股 regime 门控的目的是"熊市不开新仓，不是熊市要关闭所有仓位"。

```python
# 新增 src/backtest/regime_gate.py
class RegimeGate:
    """
    只控制新开仓许可，不强制平现有仓位。
    现有仓位由 ATR trailing / intrapos_dd / stop_loss 管理。
    """
    
    def is_entry_allowed(self, date, csi300_ohlcv) -> bool:
        """
        允许新开仓条件（同时满足）：
        1. CSI300 收盘 > MA20（短期趋势）
        2. CSI300 MA20 > MA60（中期趋势方向向上）
        条件宽松于 H-dual：不要求 MA120，不设 DD 触发器
        """
```

**与 H-dual+dd 的关键区别**：
- H-dual+dd：触发条件后**强制平所有仓位**（导致频繁进出）
- 新 RegimeGate：只拦截**新开仓**，现有仓位继续由信号和止损管理
- 恢复条件：MA20 > MA60 即可重新入场（而非等 MA120）

**实验 S3-B**：在 S3-A 最优配置上，叠加 RegimeGate：

```bash
python scripts/run_backtest_single.py \
  --symbol 300750 \
  --config configs/single_stock/300750_best.yaml \
  --enable-regime-gate \
  --regime-ma-fast 20 --regime-ma-slow 60 \
  --start 2018-01-01 --end 2026-04-30
```

**S3-B 验收**：T4（熊市）Ann 改善 ≥ 5pp（与 S3-A 最优配置对比），T3（牛市）Ann 损失 ≤ 5pp（门控不过于保守）。

### S3-C：波动率自适应仓位大小

当前始终全仓（position_size = 100%），不考虑波动率。当 300750 波动率很高时（如 T4 下跌期），全仓意味着更大的绝对亏损。

```yaml
# 波动率目标定位（20 日实现波动率）
backtest:
  volatility_target_ann: 0.30   # 目标年化波动率 30%（300750 正常波动 40-50%）
  volatility_lookback: 20
  volatility_high_vol_multiple: 1.5  # 波动 > 1.5x 时缩减仓位
  volatility_high_vol_scale: 0.5     # 缩至 50%
```

**注意**：波动率目标会在高波动（通常是熊市）时自动减仓，在低波动（通常是牛市初期）时允许更高仓位。预计 T4 MDD 改善，T3 收益略降。

## 八、Phase S4：WFO 严格验证与 OOS 最终确认

**目的**：确保 S2+S3 找到的最优配置不是 IS 过拟合，在历史危机区间有真实的 OOS 表现。

### S4-1：Walk-Forward 设计（单股专用）

针对单股 300750 的特殊历史（2018-06 上市，仅 8 年数据）：

```
WFO 折叠设计（300750 全周期 2018-06 至 2026-04）：

Fold 0（IS）：2018-06 ~ 2020-12（约 30 个月）
         OOS：2021-01 ~ 2021-12（T4 前半段，牛市转折）

Fold 1（IS）：2018-06 ~ 2021-12（约 42 个月）
         OOS：2022-01 ~ 2022-12（T4 核心熊市）

Fold 2（IS）：2018-06 ~ 2022-12（约 54 个月）
         OOS：2023-01 ~ 2024-12（T5 复苏）

Final OOS：2025-01 ~ 2026-04（最近 16 个月，从未用于任何优化）
```

这 3 折 + 1 个最终 OOS 的设计确保了：
- Fold 1 OOS = T4 熊市（最难区间）
- Final OOS = 未见过的近期数据

### R9 核心结论

1. **profit_lock 是策略利润的核心引擎**：12 次 profit_lock 退出平均收益 +19.0%，贡献了策略约 70% 的利润
2. **signal 退出是"摩擦成本"**：54 次信号反转退出平均收益为零——这是趋势跟踪策略的正常特征，频繁的小亏损被少数大盈利覆盖
3. **硬止损几乎不用**：70 笔交易中仅 1 次触发 stop_loss（-7.3%），说明 8% 硬止损是合理的安全网
4. **T4 熊市的最大问题不是止损失效，而是信号频繁摇摆**：17 笔交易中仅 1 笔触发硬止损，但 12 笔 signal 退出平均亏损 -4.1%，连亏消耗了利润
5. **单股 MDD 的本质矛盾**：300750 在 2022 年跌了 73%，任何不设 regime 门控的趋势策略都无法将 MDD 压到 40% 以下。补齐 CSI300 指数数据、实现 regime 门控是降低 MDD 的唯一路径
