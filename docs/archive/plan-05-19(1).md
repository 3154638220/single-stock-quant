### Phase F：修补 3 个结构性缺口

#### F-1：为轮动引擎添加大盘状态门控（核心新增）

**问题**：当 CSI 300 处于熊市（收盘价低于 MA200 且 MA200 向下倾斜）时，轮动引擎仍会正常建仓，缺乏系统性熊市防护。

**实现位置**：`src/backtest/rotation.py`，`run_rotation_backtest()` 函数签名新增参数：

```python
def run_rotation_backtest(
    ohlcv_map: dict[str, pd.DataFrame],
    *,
    # ... 现有参数 ...
    index_ohlcv: pd.DataFrame | None = None,    # ← 新增：CSI 300 日线
    market_regime_mode: str = "off",            # ← 新增："off" | "reduce" | "exit"
    regime_ma_period: int = 120,                # ← 新增：用 MA120 而非 MA200（A 股实践）
    regime_reduce_top_n: int = 1,               # ← 新增：熊市时降至持有 1 只
) -> RotationResult:
```

**核心逻辑**（在主循环的 rebalance 决策前插入）：

```python
# 判断当前市场状态
effective_top_n = top_n
if market_regime_mode != "off" and index_ohlcv is not None:
    idx_close = index_ohlcv["close"]
    idx_ma = idx_close.rolling(regime_ma_period, min_periods=regime_ma_period // 2).mean()
    current_close = idx_close.iloc[i] if i < len(idx_close) else np.nan
    current_ma = idx_ma.iloc[i] if i < len(idx_ma) else np.nan
    ma_slope = idx_ma.diff(5).iloc[i] if i < len(idx_ma) else np.nan
    is_bear = (
        np.isfinite(current_close) and
        np.isfinite(current_ma) and
        current_close < current_ma and
        np.isfinite(ma_slope) and ma_slope < 0
    )
    if is_bear:
        if market_regime_mode == "exit":
            effective_top_n = 0  # 全部清仓，不建新仓
        elif market_regime_mode == "reduce":
            effective_top_n = min(regime_reduce_top_n, top_n)
```

**脚本侧新增参数**：`scripts/run_rotation.py` 和 `scripts/run_stress_test.py` 加入 `--market-regime-mode {off,reduce,exit}` 和 `--regime-ma-period` 参数，支持传入 CSI 300 数据路径。

**验证实验**：在 T2（2018）和 T4（2022 新能源熊市）分别测试 `"off"` 和 `"reduce"` 两个模式的对比结果。预期 `"reduce"` 模式在 T4 年化提升 ≥ 5%。

**注意事项**：
- MA 周期选 120（约半年）而非 200（约一年），因 A 股反应速度更快，MA200 信号滞后严重
- 需要在 DuckDB 中存有 CSI 300（510300）或沪深 300 指数日线数据，或通过 `fetch_stock.py` 拉取 `000300`

#### F-2：更新 `_multi_factor_score()` 权重（E-3 实测后）

在 E-3（P1-B IC 测量）完成后，根据实测 ICIR 更新权重：

```python
# 权重更新规则：按 ICIR 比例归一化后分配
# 例如：若实测 dk_value ICIR=0.12, rs_20 ICIR=0.06, vol_adj ICIR=0.04, run_len ICIR=-0.03
# 则：只用正 ICIR 因子，比例为 0.12:0.06:0.04 → 归一化 → 0.545:0.273:0.182
```

更新规则：
1. **排除 ICIR < 0 的因子**（如 `run_len_norm`，注释已预测为负）
