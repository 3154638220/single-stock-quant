## P1 — 目标机器环境搭建

### P1-1：确认部署目标

代码库的 Dockerfile 以 Jetson/L4T 为目标（`dustynv/l4t-pytorch:r36.4.0`），但本仓库仅需 CPU + 网络。根据实际情况选择：

| 选项 | 适用场景 | 备注 |
|---|---|---|
| **Jetson Orin（裸机）** | 已有设备，长期挂机 | 推荐，低功耗 |
| **Linux 云服务器** | 无 Jetson 设备 | Ubuntu 22.04+，最小 1 vCPU / 512 MB RAM |
| **本地 Mac/Windows + cron** | 开发机兼用 | 需保证收盘后联网 |

## P2 — 生产配置与每日自动化

### P2-1：生产 config.yaml

复制模板后按实际路径和 token 填写：

```bash
cp config.yaml.example config.yaml
```

关键字段说明：

```yaml
paths:
  duckdb_path: /home/<user>/single-stock-quant/data/market.duckdb
  output_dir:  /home/<user>/single-stock-quant/data/output
  logs_dir:    /home/<user>/single-stock-quant/data/logs

akshare:
  sleep_between_symbols_sec: 1.0   # 生产建议稍保守，降低被封风险
  max_fetch_retries: 5
  retry_delay_sec: 3.0

notify:
  wecom_webhook_url: "https://qyapi.weixin.qq.com/cgi-bin/webhook/send?key=<YOUR_KEY>"
  mention_all: false                # 只在 BUY/SELL 时 @all 建议改为 true
```

**安全提示**：`config.yaml` 已在 `.gitignore` 中，不会入库。若在团队服务器部署，可用环境变量替代：

```bash
export QUANT_CONFIG=/etc/single-stock-quant/config.yaml
```

### P2-3：每日自动化（cron）

A 股每日 15:30 收盘，数据一般 16:00 前可从 Sina/Eastmoney 拉取。推荐每日 16:30 自动执行拉取 + 信号检查。

```bash
# 编辑 crontab
crontab -e
```

添加以下两行（以实际用户路径替换）：

```cron
# 每个工作日 16:30 拉取所有自选股数据（建议维护一个 watchlist 文件）
30 16 * * 1-5 cd /home/<user>/single-stock-quant && \
    .venv/bin/python scripts/fetch_stock.py \
    --symbols 600930 000001 300750 \
    --check-quality \
    >> data/logs/fetch_$(date +\%Y\%m\%d).log 2>&1

# 每个工作日 16:35 检查信号并推送企业微信（有 BUY/SELL 时）
35 16 * * 1-5 cd /home/<user>/single-stock-quant && \
    .venv/bin/python scripts/run_signal.py \
    --watchlist 600930 000001 300750 \
    >> data/logs/signal_$(date +\%Y\%m\%d).log 2>&1
```

**watchlist 扩展建议**：当自选股数量增多时，将 symbol 列表提取到 `configs/watchlist.txt`，cron 脚本改为读取该文件。

### P2-4：日志轮转

避免 `data/logs/` 无限增长：

```bash
# /etc/logrotate.d/single-stock-quant
/home/<user>/single-stock-quant/data/logs/*.log {
    daily
    rotate 30
    compress
    missingok
    notifempty
}
```

### P3-2：Docker 部署（Jetson 设备）

Dockerfile 已针对 JetPack 6.x / L4T R36.4 配置。在 Jetson 上构建：

```bash
docker build -t single-stock-quant:latest .

# 运行时注入 config（不硬编码进镜像）
docker run --rm \
    -v /home/<user>/config.yaml:/workspace/config.yaml:ro \
    -v /home/<user>/data:/workspace/data \
    single-stock-quant:latest \
    python scripts/run_signal.py --watchlist 600930 000001
```

**注意事项**：
- 镜像已排除 `data/` 目录（`.dockerignore`），数据通过 bind mount 注入。
- Jetson 无需 GPU，`dustynv/l4t-pytorch` 基础镜像体积较大（~4 GB）；若不需要 CUDA，可换用 `python:3.10-slim` 并直接 `pip install -r requirements-base.txt`，镜像体积降至 ~300 MB。
