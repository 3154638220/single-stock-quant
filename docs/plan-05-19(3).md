### 1.3 第七轮引入的新问题（Round 7 欠债）

R7 用 X3 精选 7 股替换 X1 14 股，虽整体 Calmar 首次突破 1.0，但**同时引入了三个新的结构性风险**：

**A. T4 大幅恶化（-40.60% vs +21.62%）**

根本原因：R7 为各股引入了 per-symbol Donchian 参数，600519/600887/600900 等防御股采用了较慢的 Donchian 突破参数（entry_window 25–40），在 2022 年新能源熊市期间，这些股票的价格本身也处于下行通道，Donchian 参数产生了大量亏损交易（进入后快速止损）。R6 的 +21.62% 来自于 300750 在 MA120 exit 框架下的严格市场门控（未进场），而 X3 的防御股仍在交易，累计了大量小额止损。

**B. 300750 集中风险进一步恶化（去除后 30.68pp 损失）**

R7 X3 池的独立 alpha 依然几乎全部来自 300750：其他 6 只股票的组合年化仅 0.74%。相比 R6 的 2.13%，X3 的"多 alpha"宣传实为 300750 一股带动的幻觉——行业分散（新能源+银行+白酒+乳业+电力）并未带来真正的 alpha 分散。

**C. Bootstrap P5 MDD 未改善（-45.30%，差 10pp）**

H-dual+dd 在期望路径（压力测试实测值）表现良好，但在 Bootstrap 的极端路径下，MDD 尾部风险并未收敛到目标范围。这说明 H-dual+dd 的保护是路径依赖的，而非结构性的。

参数网格（聚焦 Donchian 参数，避免过拟合）：

**决策规则**：若某只股票的 WFO OOS Sharpe 在当前 `symbol_params.yaml` 参数下 ≥ 0.20，则保留；否则回退到全局参数（`donchian_entry_window=20, exit_window=10`）。

## 六、Phase N：生产落地与代码健康

### N-1：X3 轮动策略的生产流水线

**核心缺口**：`daily_update.sh` 使用的是 R4 的单股 WFO 策略，而 R7 验证的是 X3 轮动策略。两者没有桥梁。

**新增脚本**：`scripts/daily_rotation_update.sh`

```bash
#!/bin/bash
# daily_rotation_update.sh — X3 轮动策略的每日执行流
# crontab: 30 16 * * 1-5 /path/to/scripts/daily_rotation_update.sh

set -euo pipefail
ROOT="$(cd "$(dirname "$0")/.." && pwd)"
WATCHLIST="$ROOT/configs/watchlist_x3.txt"
SYMBOL_PARAMS="$ROOT/configs/symbol_params.yaml"
SECTOR_MAP="$ROOT/configs/sector_map.yaml"
STATE_FILE="$ROOT/data/rotation_state/current_positions.json"

# 1. 更新 X3 池数据
while IFS= read -r sym; do
  [ -z "$sym" ] || [[ "$sym" == \#* ]] && continue
  python "$ROOT/scripts/fetch_stock.py" \
    --symbol "$sym" --check-quality --fail-on-quality \
    --quality-min-rows 5 2>&1
  sleep 2
done < "$WATCHLIST"

# 2. 计算当日轮动信号
python "$ROOT/scripts/run_rotation.py" \
  --watchlist "$WATCHLIST" \
  --symbol-params "$SYMBOL_PARAMS" \
  --sector-map "$SECTOR_MAP" \
  --ranking-mode trend_strength \
  --top-n 1 --rebalance-freq 10 \
  --market-regime-mode exit \
  --regime-fast-ma-period 60 \
  --regime-slow-ma-period 120 \
  --regime-drawdown-trigger 0.15 \
  --export-results \
  --output-state "$STATE_FILE"  # 新增：导出当前持仓状态

# 3. 发送轮动通知（新增）
python "$ROOT/scripts/notify_rotation.py" \
  --state-file "$STATE_FILE" \
```

### 12.1 核心实验结论

**L-1：per-symbol 参数是 T4 恶化的根因（确认）**
