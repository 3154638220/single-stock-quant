# single-stock-quant 单股收益提升计划

**更新日期**：2026-05-17  
**唯一目标**：提升指定单只 A 股的量化交易收益。

本计划只服务一个问题：在真实交易约束和样本外评估下，怎样让单股策略赚得更多。复刻指标、组合配置、通用选股、展示报表和生产自动化都不是当前目标；只有当它们能直接提升单股收益或避免虚假收益时，才纳入本计划。

| 矛盾 | 对收益的影响 |
|---|---|
| 慢均线版本回撤低但交易少 | 收益容易依赖少数行情 |
| 短均线版本收益更高但回撤更大 | 需要更强出场和仓位控制 |
| WFO fold 太少 | 难判断收益是真 Alpha 还是行情偶然 |
| 现有网格仍残留锚点诊断字段 | 研究注意力容易偏离交易收益 |

## 2. 收益提升原则

1. 主指标是扣除成本后的 OOS 总收益、年化收益和 Calmar；Sharpe 是辅助指标。
2. 全样本收益只能做候选筛选，不能作为最终结论。
3. 不通过加杠杆制造收益提升；默认仍按现有单股资金曲线口径评估。
4. 任一改动如果只提升收益但显著扩大最大回撤、单笔集中度或参数漂移，先降级为研究候选。
5. 当前只优化单股收益，不追求跨股泛化；跨股结果只用于识别“这个策略是否只适合某些股票”。

| 层级 | 通过条件 |
|---|---|
| 初筛 | 全样本收益为正，且明显跑赢买入持有或以更低回撤取得相近收益 |

| 交易结构 | 至少有多笔独立交易贡献收益，不能由单笔大赢家解释全部表现 |

## 4. 收益杠杆

### 4.1 参数搜索从“像不像”改为“赚不赚”

当前网格输出仍保留历史锚点列，这些列只做诊断，不进入排序。后续所有搜索默认按交易收益排序：

| 动作 | 目的 |
|---|---|
| 新增或统一 `return_quality` 排序 | 让最高优先级回到收益、回撤和交易结构 |
| 将锚点命中率从目标函数中移除 | 避免为了视觉相似牺牲交易表现 |
| 对高收益区间做二次细网格 | 重点围绕 `sma60/wma5-20/c1-c2` 和 `sma205/wma5/c3` 两类候选 |

### 4.2 出场层优先优化

当前收益瓶颈更像“能抓到方向，但卖点决定利润保留率”。优先验证：

| 实验 | 假设 |
|---|---|
| `intrapos_dd_limit` 细分 0.04/0.05/0.06/0.07/0.08 | 更早保护浮盈可提升复利收益 |
| ATR trailing stop | 对短均线高收益候选降低回撤 |
| 趋势衰减退出 | DK 值或均线斜率连续走弱时提前离场 |
| 时间止损 | 清理无效持仓，提高资金周转 |
| 分段止盈保护 | 大幅盈利后不等趋势完全翻绿 |

### 4.3 入场层只做能增加收益的改造

| 实验 | 假设 |
|---|---|
| 新近转多入场 | 避免追入已老化趋势 |
| Donchian 突破确认 | 过滤弱反弹，提高单笔期望 |
| MA slope / price above MA 过滤 | 避免下行大趋势中的假多头 |
| 成交量确认 | 只保留有资金推动的信号 |
| MACD 二次确认 | 减少短均线参数带来的噪声交易 |

### 4.4 仓位层服务收益复利

| 实验 | 假设 |
|---|---|
| 波动率目标仓位 | 高波动期少亏，低波动趋势期吃满 |
| 信号质量缩放仓位 | 高质量信号承担更多风险，低质量信号轻仓 |
| 浮盈后动态保护 | 提高大赢家留存率 |

## 5. 执行顺序

### P0：把收益排序链路统一

1. 明确所有网格、WFO、报告的主排序字段为 `return_quality`。
2. `return_quality` 至少包含 OOS 年化收益、总收益、最大回撤、Calmar、交易数、单笔集中度。
3. 输出候选榜单时，把锚点诊断列降级到附录或 legacy 字段。
4. 修复 WFO JSON 的 `NaN/inf` 输出，避免后续自动汇总失败。

### P1：围绕 000783 做收益二次搜索

1. 以当前 WFO 基线参数为低回撤基线：`sma205/wma5/c3`。
2. 以全样本高收益区间为进攻基线：`sma60/wma5-20/c1-c2`。
3. 分别叠加出场层实验，比较收益提升来自入场还是出场。
4. 对每个候选输出交易级贡献表，确认不是单笔交易支撑收益。

### P2：做更可靠的 OOS 检验

1. 调整 WFO 切分，让 000783 至少有 3-4 个 OOS fold。
2. 对最佳候选跑 nested WFO 或固定参数滚动验证。
3. 输出 bootstrap、fold 分解、年度收益、最大单笔贡献。
4. 若 OOS 收益提升不成立，回退到上一版基线。

### P3：单股适配扩展

1. 只选择与 000783 行情结构相近的标的做验证，例如趋势性强、流动性足、长周期数据完整。
2. 每只股票独立选参，不要求一套参数横跨所有股票。
3. 形成“可交易 / 观察 / 放弃”三类结论。
4. 扩展验证只用于找到更多可交易单股，不用于证明通用策略。

## 6. 实验记录格式

每次实验至少记录以下字段：

| 字段 | 说明 |
|---|---|
| `experiment_id` | 实验编号，例如 `R01_exit_dd_006` |
| `symbol` | 股票代码 |
| `entry_rule` | 入场规则 |
| `exit_rule` | 出场规则 |
| `position_rule` | 仓位规则 |
| `total_return_oos` | OOS 总收益 |
| `annualized_return_oos` | OOS 年化收益 |
| `max_drawdown_oos` | OOS 最大回撤 |
| `calmar_oos` | OOS Calmar |
| `n_trades` | 交易笔数 |
| `largest_trade_contribution` | 最大单笔贡献 |
| `decision` | promote / retry / reject |

## 8. 明确不做

- 不再复刻东方财富官方曲线。
- 不再以截图锚点命中率作为优化目标。
- 不为了证明策略通用而扩大跨股样本。
- 不把组合收益作为当前目标。
- 不做无法解释、无法复现或只在全样本上有效的收益提升。
