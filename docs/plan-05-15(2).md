# single-stock-quant 改进计划：复刻东财多空趋势红绿柱

**日期**：2026-05-15  
**基础版本**：`single-stock-quant-main`  
**核心目标**：从根本上修复 DK 指标，使其复现东方财富主图"多空趋势"的红绿柱状态、`LST/BARHIGH/BARLOW` 数值，并用红绿状态切换指导交易。

---

## 零、目标校正：复现对象是红绿柱，不只是橙色线

最新东财截图明确显示，"多空趋势"不是一个单独的 MACD 副图柱体，也不只是主图里的橙色趋势线，而是一套主图覆盖指标：

| 输出项 | 截图示例 | 含义 |
|---|---:|---|
| `LST` | `7.66 ↑` | 多空趋势的长期基准线或最近趋势止损线，图中为橙色线 |
| `BARHIGH` | `8.38 ↑` | 多空红绿柱的当前上沿，不等同于当日最高价 |
| `BARLOW` | `8.35 ↑` | 多空红绿柱的当前下沿，不等同于当日最低价 |
| `bar_color` | 红 / 绿 | 多空状态，用于交易信号；不应简单等同于日 K 涨跌颜色 |

因此本计划的工程目标必须从单一 `dk_value` 改为结构化输出：

```text
lst        # 橙色 LST 线
bar_high   # 多空柱上沿
bar_low    # 多空柱下沿
bar_mid    # 多空柱中心或代表值
bar_color  # red / green
signal     # green->red 买入，red->green 卖出
run_len    # 当前同色状态持续天数
```

交易逻辑也应以状态切换为核心：

| 状态变化 | 操作含义 |
|---|---|
| 绿 -> 红 | 多头启动，买入或加入候选 |
| 红持续 | 持有 |
| 红 -> 绿 | 多头结束，卖出或减仓 |
| 绿持续 | 空仓等待 |

橙色 `LST` 仍然重要，但它只是红绿柱状态机的一部分。后续所有视觉验证和回测验收，都必须同时检查 `LST/BARHIGH/BARLOW/bar_color`。

## 一、失败根因深度分析

### 根因 1：指标输出错了——MACD 柱体 ≠ 东财多空红绿柱

这是所有问题的总根源。

**当前代码实际做了什么**（`src/indicators/dktrend.py`）：

```python
fast = ema(close, 12)
slow = ema(close, 26)
diff = fast - slow        # MACD 的 DIFF 线
dea  = ema(diff, 9)       # MACD 的 DEA（信号线）
dk_value = diff - dea     # ← 这是 MACD 柱体（HISTOGRAM），不是趋势线
```

`dk_value` 是 EMA(12) 减 EMA(26) 再减其9日均线。数学上它更接近价格的高阶差分，描述的是**短期动量加速度**，不是东财主图里的多空红绿柱。

**东财截图告诉我们什么**：

截图中的关键视觉特征：
- 橙色 `LST` 线极度平滑，没有锯齿，位于价格下方
- 主图 K 线区域存在一组红绿多空柱，其当前上下沿由 `BARHIGH/BARLOW` 标注
- `BARHIGH/BARLOW` 与当日最高价/最低价不是同一个东西，例如截图中当日最高 `8.76`、最低 `8.36`，但 `BARHIGH=8.38`、`BARLOW=8.35`
- 红绿柱颜色表达多空状态，不应简单等同于日 K 涨跌颜色
- 全图只有少量多空状态切换，符合中长周期趋势状态机，而不是高频震荡指标

这描述的是一个**主图趋势状态指标**：长期 `LST` 基准线 + 近端 `BARHIGH/BARLOW` 柱体 + 红绿状态机。当前代码只输出一个 MACD 柱体标量，缺少东财指标最关键的绘图结构和状态结构。

**信号切换频率对比**：

| 指标 | 年切换次数（估算） | 对应持仓天数 |
|---|---|---|
| MACD(12,26,9) 柱体正负 | 20–40 次 | 5–15 天 |
| EMA(26) 穿越 EMA(120) | 4–8 次 | 30–90 天 |
| 价格穿越 EMA(250) | 2–5 次 | 60–180 天 |
| 东财多空趋势（截图） | **2–4 次** | **40–200 天** |

当前实现频率是东财的 **10–15 倍**，产生大量噪声交易。

---

### 根因 2：趋势判断逻辑与东财相反

东财多空趋势的颜色切换逻辑（逆向工程推断）：

- **红（多头）**：多空柱上移并维持在 `LST` 之上，或趋势状态机确认上行
- **绿（空头）**：多空柱下移并跌破 `LST`，或趋势状态机确认下行
- **交易信号**：来自 `bar_color` 的状态切换，而不是来自某个普通振荡指标的正负号

当前代码的切换逻辑：

- **红**：MACD 柱体从负转正（仅代表短期动量加速，价格不一定在均线上方）
- **绿**：MACD 柱体从正转负

两者描述的是完全不同的市场状态。MACD 柱体转正时，价格可能仍在下跌（只是下跌动能减弱了）。这导致大量在错误位置买入。

---

### 根因 3：EMA 初始化存在系统性偏差

```python
# src/indicators/utils.py
def ema(series, period):
    return s.ewm(span=period, adjust=False, min_periods=period).mean()
```

`adjust=False` + `min_periods=period`：序列开始时的前 `period-1` 个点会被舍弃，但一旦有 `period` 个点，EMA 就直接用冷启动的初始值开始计算，没有经过充分预热。

东财系统有完整的历史数据，EMA 已经经过数年预热，初始偏差为零。对于 EMA(250) 这样的长周期指标，冷启动误差可能持续 3–6 个月。

**量化影响**：若数据从 2020-01-01 开始，EMA(250) 要到 2020-12-01 才算稳定，前 11 个月的信号完全不可信。

---

### 根因 4：出场极度滞后——从高点到卖出损失 15–25%

从价格高点到 `dk_signal = "sell"` 的时间链：

```
价格见顶 (t=0)
    ↓ ~5 天
EMA(12) 开始下弯
    ↓ ~8 天
DIFF = EMA(12) - EMA(26) 转为负增长
    ↓ ~12 天
DEA = EMA(DIFF, 9) 开始滞后跟随
    ↓ ~15–25 天
柱体 = DIFF - DEA < 0 → dk_color 变绿 → dk_signal = "sell"
    ↓ +1 天（T+1 执行）
最终卖出（距高点已过去 16–26 天）
```

000783 Fold 2 典型案例：`#5（2025-09-30 买入 8.32，2025-10-09 卖出 8.29）`——这笔交易恰好在一次反弹后被 profit_lock 以 −0.51% 退出，正是因为信号迟钝、依靠 profit_lock 托底却还是亏损的写照。

---

### 根因 5：profit_lock 在低价股上制造系统性摩擦

000783 股价区间：5–9 元。配置：`profit_lock_trigger=0.08`，`profit_lock_trailing=0.04`。

- 8% 触发阈值 → 绝对价格需涨 0.40–0.72 元
- 触发后 4% trailing → 从高点回落 0.16–0.28 元即止盈

对于日内振幅约 0.3–0.5% 的低价股，0.20 元的回撤等于 0.15–0.20 个 tick，随机波动即可触发。

后果：见 Fold 0 中 5 笔 profit_lock 退出，全部在买入后 1–3 天内触发，收益为 −0.15%、−0.67%、−2.05%、−0.53%——profit_lock 把正常波动误判为"要止盈"，结果切在了底部。

### 根因 6：策略成功完全依赖一次不可复制的系统性事件

000783 WFO OOS 全部收益分布：

| Fold | 总收益 | 主要来源 |
|---|---|---|
| Fold 0 | −2.7% | 无大行情，7 次试错均亏 |
| Fold 1 | **+49.9%** | 2024-09-09 买入，捕捉 924 行情 +54.4% |
| Fold 2 | −0.0% | 震荡市，9 次打平 |

如果移除 2024-09-09 这笔交易：三个 Fold 合计 **−7.1%**，Sharpe **−0.5 以下**。

这不是策略的功劳，而是恰好在 924 央行政策刺激前夕入场（4.88 元）持仓一个月。即便是随机持股，此区间也能获得类似收益。策略本身没有提供有效的选时价值。

### 根因 7：WFO 参数空间选错了优化对象

当前 WFO 优化的是：`macd_fast ∈ [10,12,14] × macd_signal ∈ [8,9,10]`（9 个组合）

这些都是 MACD 的超短周期参数，在 756 天训练窗口内变化极小（信号次数差异仅 ±2–3 次）。参数选择等同于噪声。

真正该优化的是：**东财红绿柱状态机参数**，包括 `LST` 周期、`BARHIGH/BARLOW` 生成方式、翻色确认天数和滞回阈值。这些参数才决定红绿柱何时翻色、持仓周期多长，以及交易信号是否接近东财。

## 二、东财多空趋势逆向工程

根据截图特征 + 中文量化社区的逆向分析（非官方，供参考）：

### 截图关键参数解读

| 标注 | 含义 |
|---|---|
| `LST:7.66` | 主图橙色线的当前值，可能是趋势基准线或多头止损线 |
| `BARHIGH:8.38 / BARLOW:8.35` | 多空红绿柱的当前上下沿，不是原始日线高低点 |
| `LST/BARHIGH/BARLOW` 后的箭头 | 指标内部三个序列的当日方向 |
| 红绿柱 | 多空状态柱，用于交易决策；颜色不等于普通日 K 涨跌 |
| 右端日期 `20260203` | 当前截图锚点，可作为数值校准日 |

关键校准锚点：

| 日期 | 收盘价 | 原始高/低 | 东财 `LST` | 东财 `BARHIGH` | 东财 `BARLOW` |
|---|---:|---:|---:|---:|---:|
| 2026-02-03 | 8.46 | 8.76 / 8.36 | 7.66 | 8.38 | 8.35 |

该锚点说明：`BARHIGH/BARLOW` 更像指标内部的压缩趋势柱或状态柱上下沿，而不是 OHLC 的直接复制。

### 可能的指标公式

**假说 A（最优先）：`LST` 长周期基准 + 多空柱状态机**

```
lst = smooth(close_or_typical_price, N)     # N ∈ [120, 250]
bar_mid = smooth(typical_price, M)          # M ∈ [5, 30]
bar_range = smooth(true_range, R) * k       # 压缩后的柱体高度
bar_high = bar_mid + bar_range / 2
bar_low = bar_mid - bar_range / 2

红：bar_low > lst 且 lst_slope >= 0
绿：bar_high < lst 或 lst_slope < 0
保持原色：未满足反向确认，避免频繁翻色
```

这是最贴近截图结构的假说：`LST` 负责趋势底线，`BARHIGH/BARLOW` 负责绘制红绿柱，颜色由状态机确认。

**假说 B：SuperTrend / ATR Trailing Stop 变体**

```
mid_price = (high + low) / 2
atr = ATR(period)
upper_band = mid_price + mult * atr
lower_band = mid_price - mult * atr

多头时：lst = max(prev_lst, lower_band)
空头时：lst = min(prev_lst, upper_band)
红绿：close 与 lst 的穿越状态
bar_high/bar_low：使用平滑后的短周期价格柱
```

这可以解释为什么 `LST` 在多头阶段位于价格下方，并像追踪止损线一样缓慢上移。

**假说 C：中文 DKX 多空线加信号线**

```
mid = (3 * close + low + open + high) / 6
dkx = weighted_ma(mid, weights=20..1)
signal = ma(dkx, M)

红：dkx > signal
绿：dkx < signal
lst/bar_high/bar_low：由 dkx/signal/平滑价格组合派生
```

该假说对应中文量化社区常见的"DKX 多空线"公式，适合作为第二轮拟合候选。

**假说 D：价格 vs 长期 EMA（只能作为 `LST` 近似）**

```
trend_line = EMA(close, N)   # N ∈ [120, 250]
多头（红）：close > trend_line  且  trend_line 斜率 > 0
空头（绿）：close < trend_line  或  trend_line 斜率 < 0
```

这个假说可以解释橙色线的大致位置和低切换频率，但不能直接解释 `BARHIGH/BARLOW`，因此只能作为基线，不应作为最终复刻方案。

**假说 E：双均线交叉（备用）**

```
fast_ma = EMA(close, 30)
slow_ma = EMA(close, 120)
多头（红）：fast_ma > slow_ma
空头（绿）：fast_ma < slow_ma
```

仅用于交易状态对照，不用于视觉复刻。

### 验证方法

用以下方式对历史数据标注多空区间，与东财截图对比：
1. 在相同时间段跑上述假说，输出 `lst/bar_high/bar_low/bar_color`
2. 对齐截图锚点：2026-02-03 应接近 `LST=7.66, BARHIGH=8.38, BARLOW=8.35`
3. 逐日人工抽样对比东财红绿柱颜色，确认颜色不是普通日 K 涨跌色
4. 统计红绿切换次数，目标仍是年切换约 2–5 次
5. 用 `green->red` 和 `red->green` 作为买卖信号重跑交易回测

## 四、阶段 A：指标重设计（最优先）

### A.1 新增 `eastmoney_dkbar` 模式

在 `src/indicators/dktrend.py` 中新增 `TrendMode.EASTMONEY_DKBAR`，并保留 `LONG_MA_TREND` / `DUAL_MA_CROSS` 作为对照基线：

```python
# TrendMode 枚举新增
EASTMONEY_DKBAR = "eastmoney_dkbar"  # LST + BARHIGH/BARLOW + 红绿状态机
LONG_MA_TREND = "long_ma_trend"      # 仅用于 LST 近似和低切换频率基线
DUAL_MA_CROSS = "dual_ma_cross"      # 快慢均线交叉对照
```

**`eastmoney_dkbar` 首版实现**：

```python
if mode == TrendMode.EASTMONEY_DKBAR:
    typical = (3 * close + low + open_ + high) / 6

    # 1. 橙色 LST 候选：长周期平滑线或追踪止损线
    lst = smooth(typical, params.lst_period, method=params.lst_method)
    lst_slope = lst - lst.shift(params.slope_lookback)

    # 2. 红绿柱上下沿：短周期平滑价格 + 压缩波动宽度
    bar_mid = smooth(typical, params.bar_period, method=params.bar_method)
    bar_width = smooth(high - low, params.bar_range_period) * params.bar_range_mult
    bar_high = bar_mid + bar_width / 2
    bar_low = bar_mid - bar_width / 2

    # 3. 状态机：带确认和滞回，避免一天假突破就翻色
    raw_red = (bar_low > lst) & (lst_slope >= -params.slope_tolerance)
    raw_green = (bar_high < lst) | (lst_slope < -params.slope_tolerance)
    dk_color = confirm_state(raw_red, raw_green, days=params.state_confirm_days)

    dk_value = bar_mid - lst
    dk_signal = color_transition_signal(dk_color)

    return pd.DataFrame(
        {
            "dk_value": dk_value,
            "dk_color": dk_color,
            "dk_signal": dk_signal,
            "lst": lst,
            "bar_high": bar_high,
            "bar_low": bar_low,
            "bar_mid": bar_mid,
            "trend_run_len": run_length(dk_color),
        },
        index=df.index,
    )
```

**`long_ma_trend` / `dual_ma_cross` 实现**：

这两个模式仍保留，但定位变为"基线模型"：
- `long_ma_trend`：评估哪种长周期平滑最接近 `LST`
- `dual_ma_cross`：评估低频红绿切换是否能改善交易结果
- 二者都不能单独声明为东财红绿柱复刻

```python
if mode == TrendMode.DUAL_MA_CROSS:
    # params.ma_fast: 30 | 45 | 60
    # params.ma_slow: 120 | 180 | 250
    fast = close.ewm(span=params.ma_fast, adjust=False,
                     min_periods=params.ma_fast).mean()
    slow = close.ewm(span=params.ma_slow, adjust=False,
                     min_periods=params.ma_slow).mean()
    # dk_value = fast - slow，正数 = 多头；仅作为低频状态基线
    dk_value = fast - slow
    return dk_value
```

### A.3 修复 EMA 预热问题

当前：`min_periods=period` 导致长周期平滑线前 `period` 天不可用，而且冷启动误差会污染 `LST` 和红绿状态。

改进：所有用于 `LST` 的平滑方法都必须支持预热数据，并以第一个有效窗口的 SMA 作为 EMA 起始种子：

```python
def ema_seeded(series: pd.Series, period: int, warmup_mult: float = 2.0) -> pd.Series:
    """EMA with SMA-seeded initialization to reduce cold-start bias."""
    s = pd.to_numeric(series, errors="coerce")
    # Use SMA of first period as seed
    sma_seed = s.rolling(period, min_periods=period).mean()
    first_valid = sma_seed.first_valid_index()
    if first_valid is None:
        return s.ewm(span=period, adjust=False).mean()
    seed_value = sma_seed.loc[first_valid]
    # Start EMA from SMA seed
    result = s.ewm(span=period, adjust=False, min_periods=period).mean()
    # Override: before first_valid, set to NaN; at first_valid, use SMA
    result.loc[:first_valid] = np.nan
    return result
```

生产计算时应至少向前多取 `max(2 * lst_period, 252)` 个交易日作为 warmup，再裁剪到用户指定区间。

## 六、阶段 C：出场机制重构

### C.1 问题诊断

当前出场层级（按触发顺序）：
1. `profit_lock`：+8% 后 trailing 4%（低价股摩擦过高）
2. `stop_loss`：-8%（从未触发，说明设置过宽）
3. `dk_signal = "sell"`：MACD 柱体翻负（不是东财红绿柱翻绿）
4. `time_stop`：30 天（偶发）

问题：出场层 1 和 3 互相矛盾。profit_lock 在小幅上涨时抢先出场，导致错过大趋势行情；当前 `dk_signal` 又不是东财红绿柱状态切换，无法验证是否真的跟随东财趋势。

### C.2 新出场方案

**方案一（推荐）：红绿柱翻色出场**

与东财交易含义完全对称：

```python
# 入场：bar_color 从 green 变 red
# 出场：bar_color 从 red 变 green

if dk_signal == "sell" and position == LONG:
    signal = "sell"
```

优点：交易信号与复刻目标一致，不再混用 MACD 柱体、均线跌破和 profit_lock 三套互相冲突的逻辑。

**方案二：ATR 倍数 Trailing Stop**

```python
# 替代固定 8%/4% 的 profit_lock
atr_14 = compute_atr(df, period=14)
trailing_stop = entry_price + cumulative_high_since_entry - 2.5 * atr_14
# 每日更新 trailing_stop
if close < trailing_stop:
    signal = "sell"
```

优点：自动适应不同价格区间的波动率，不会在低价股上过于灵敏。

**方案三（两者结合，推荐最优）**：

```python
exit_triggers = [
    # 1. 东财多空柱翻绿（主要出场）
    dk_color_changed_to_green(),
    # 2. ATR Trailing（风控保底）
    close_below_entry_trailing_atr(mult=2.5),
    # 3. 时间止损（兜底）
    holding_days > 45 and return_pct < 0.02,
]
if any(exit_triggers):
    signal = "sell"
```

### C.3 移除或改造 profit_lock

`profit_lock_trigger=0.08` 对于 5–9 元股票是合理的，但 `profit_lock_trailing=0.04` 太紧。建议：

```yaml
# 新配置
profit_lock_trigger: 0.12   # 提高到 12%，减少过早锁利
profit_lock_trailing: 0.06  # 提高到 6% trailing

# 或者完全换成 ATR 倍数
profit_lock_enabled: false
atr_trailing_mult: 2.5
atr_trailing_min_gain: 0.08  # 至少涨 8% 才激活 ATR trailing
```

### D.3 评分函数优化

当前 `_composite_score = 0.45*Sharpe + 0.25*Calmar + 0.15*AnnReturn - 0.10*MDD`

在信号次数 < 30 的情况下，Sharpe 估计误差 ±0.3+，不可靠。

改进：加入样本数惩罚项：

```python
def composite_score(sharpe, calmar, mdd, n_trades):
    if n_trades < 8:
        return -999  # 信号太少，直接排除
    reliability_discount = min(1.0, n_trades / 20.0)
    raw_score = 0.50 * sharpe + 0.30 * calmar - 0.20 * mdd
    return raw_score * reliability_discount
```

## 十一、不应继续的方向

以下是已经投入大量时间但回报率极低的方向，建议暂停：

| 方向 | 原因 |
|---|---|

| 增加更多 `signal_filter`（volume/ADX 叠加） | 在噪声信号上叠加过滤器只会减少交易次数，不能提高信号质量 |
| GBM meta-label 进一步优化 | 在 MACD 信号基础上，训练样本不足，模型无法学到有用知识；先把信号质量提上来 |
| 扩大 WFO 参数网格（>50 组合） | 样本不足时，大网格等于噪声搜索，IS/OOS 相关性只会更差 |
| 组合层继续叠加机制 | 单股 OOS Sharpe 中位不达 0.40 之前，组合层无法放大 alpha |
