## 0. 执行摘要

### 已确认事实

1. 旧版 DK 指标本质是 MACD histogram，不是东财“多空趋势”。
2. 东财指标是主图覆盖结构，至少包含：
   - `LST`：橙色平滑趋势线
   - `BARHIGH/BARLOW`：红绿柱上下沿，不等于原始 high/low
   - `bar_color`：红绿柱视觉颜色
3. 新增 7 个锚点后，已证明：
   - `bar_color` 不能直接等同于 `BAR` 在 `LST` 上下的位置
   - `bar_color` 不能直接作为交易买卖状态
   - 交易状态必须与视觉颜色拆分
4. 当前工程已拆分：
   - `bar_color/bar_run_len`：视觉复刻层
   - `trend_state/trend_run_len`：交易状态层
   - `dk_color/dk_signal/dk_run_len`：兼容旧接口，映射到 `trend_state`

### 当前结果

| 项目 | 当前状态 |
|---|---|
| 工程结构 | 已完成首版拆分 |
| `LST/BARHIGH/BARLOW` | `SMA205/WMA5` 收益候选较稳，但 BAR MAE 仍未达复刻标准 |
| `bar_color` | `persistent_sma205_wma5` 6/7 |
| `trend_state` | 收益优先候选已转正，但仍不是东财官方状态 |
| 000783 回测 | `SMA205/WMA5/state_confirm=3`：到 `2026-05-15` 总收益 `+20.61%`，Sharpe `0.37` |
| 全量测试 | `pytest -q` 通过 |

### 核心判断

当前不能宣称复刻成功。下一阶段重点不是跑更多回测，而是先解决两个逆向问题：

1. 锚点只作为视觉约束，不再作为唯一优化目标。
2. 校准排序应优先看收益质量：收益、Sharpe、最大回撤、交易次数。
3. `bar_color` 仍不能直接交易，交易信号继续来自独立的 `trend_state`。

## 3. 旧方案处置

### 已废弃

| 方案 | 处置原因 |
|---|---|
| MACD histogram 当 DK 指标 | 指标对象错误 |
| `bar_color` 直接做买卖信号 | 被锚点反例推翻 |
| 单点拟合 2026-02-03 | 容易过拟合 |
| 直接扩展 25 只标的 | 视觉和交易状态尚未校准 |
| 继续扩大 MACD/WFO 参数网格 | 优化对象错误 |

### 暂时保留

| 机制 | 用途 |
|---|---|
| `trend_state` | 交易层临时状态，后续继续校准 |
| ATR trailing | 风控替代 `profit_lock` |
| WFO 可靠性折扣 | 后续低频策略仍需要 |
| `bar_color_method=price_change` | 视觉层基线方法，不是最终答案 |


候选方法：

| 方法 | 逻辑 |
|---|---|
| `price_change` | close >= prev_close 为 red，否则 green |
| `bar_slope` | bar_mid 上升为 red，否则 green |
| `persistent_price_change` | 趋势强时回调 N 天内保持原色 |
| `bar_mid_vs_signal` | bar_mid 与短信号线关系决定颜色 |
| `dkx_color` | DKX 与 DKX signal 的位置/斜率决定颜色 |

建议优先实现：

```text
persistent_price_change
```

初版规则：

```text
base_red = close >= prev_close
strong_up = trend_state == red and bar_mid > lst
if previous bar_color == red and red_run >= min_red_run and strong_up and pullback_days <= hold_days:
    bar_color = red
else:
    bar_color = red if base_red else green
```

验收：

- 7 个锚点 `bar_color` 命中率 ≥ 6/7。
- 不能靠手写日期特例。
- 输出每个锚点的命中/错误原因。

### E24：交易层 `trend_state` 重定义

| 方法 | 逻辑 |
|---|---|
| `lst_trailing_state` | close 与 LST trailing stop 关系 |
| `bar_mid_lst_state` | bar_mid 与 LST 的位置 + 斜率 |
| `dual_state` | fast trend line 与 LST 的交叉 |

- 000783 不再出现 2024-10 高位追入后快速止损的典型错误，或该错误有明确风控解释。
