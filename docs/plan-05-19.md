## 一、当前收益现状评估：是否令人满意？

### 1.1 数字层面的结论

| 维度 | 单标的 WFO 框架 | X1 轮动框架（2024-2026 测试期） | 晋级线要求 |
|---|---|---|---|
| 年化收益 | 最高 14.04%（300750） | **26.74%** | ≥14% |
| Calmar 比率 | 最高 0.57（300750） | **1.64** | ≥1.30 |
| 最大回撤 | 最低 14.81%（601398，但年化仅 2.7%） | **16.30%** | ≤15% |
| OOS 交易数 | 最高 47 笔 | **67 笔** | ≥8 |
| 达标评定 | **零达标（22+ 次全军覆没）** | **✅ 可交易配置** | — |

**X1 轮动框架是 22+ 次实验以来的首次真正突破**，在 2024-2026 测试期达到「可交易配置」等级。

### 1.2 深层缺陷：令人满意的背后

尽管数字达标，以下五点令人**不能完全满意**：

#### ① 单 alpha 源集中风险

300750（宁德时代）是策略的唯一核心 alpha 来源：

```
全部 5 只（含 300750），MACD，周度 → 年化 21.74%
全部 5 只（去除 300750），MACD，双周度 → 年化 6.84%
```

去除一只股票，策略从「可交易」降级为「无效」。这意味着策略实质上是一个「宁德时代趋势跟踪策略」加了两只能源股做伴侣，而非真正的多标的轮动。

#### ② 熊市韧性不足

| 时期 | 市场特征 | 策略表现 |
|---|---|---|
| 2018-2023（训练） | 混合牛熊 | 33.44% 年化 |
| 2024-2026（测试） | 以牛为主 | 26.74% 年化 |
| 2022-2024（逆向测试） | 2022 大熊市 | **4.93% 年化** |

2022-2024 熊市期间仅 4.93%，意味着在真实 A 股完整周期中，策略的熊市保护能力依赖于「宁德时代不崩」这一隐性假设。

#### ③ MDD 仍略超理想目标

2024-2026 测试期 MDD=16.30%，超出理想目标 ≤15% 约 1.3 个百分点。尚在最低要求（≤18%）内，但距理想目标仍有差距。

#### ④ 轮动参数存在隐性过拟合

top-n=2、双周度 rebalance、3 只股票组合——这些参数是通过观察不同配置的回测结果决定的，而非通过独立的参数验证流程（WFO）确定的。这构成隐性的「回测内选参」偏差。

#### ⑤ 排名评分原始

当前 `_trend_strength_score` 函数：
```python
return dk_value * (1.0 + run_len / 10.0)
```
这是一个未经统计验证的启发式公式，权重完全凭感觉设定，既没有动量因子，也没有波动率归一化，更没有经过任何 IC（信息系数）验证。

### 1.3 综合结论

**部分令人满意**：X1 框架在近期牛市环境下达标，证明了「多标的轮动 + 固定参数」的技术路线正确，是明确的进展。但策略在当前状态下不适合实盘，核心原因是单 alpha 依赖和排名系统未经验证。**需要完成第五轮计划才能真正接近可部署状态**。

## 二、项目与模型不足深度分析

### 2.1 框架层面的结构性不足

#### 不足 A：IS 评分函数不惩罚回撤（`_composite_score`）

**位置**：`src/backtest/wfo.py`，`_composite_score()`

**问题**：IS 评分包含 `max_drawdown_limit=0.35` 作为硬约束（MDD > 35% 直接淘汰），但 MDD 在 0% 到 35% 之间时，评分中的 `dd_score` 权重仅 15%，而 `w_calmar=0.35`、`w_sharpe=0.25`、`w_total_return=0.15`。

```python
# 现有评分（有问题）
dd_score = max(0.0, 1.0 - res.max_drawdown * 2.0)  # MDD=15% → score=0.70，MDD=20% → score=0.60，差异极小
```

实验证据（P0-B 全网格）：IS 优化器在 11/11 个 fold 中选择 `atr_trailing_mult=0`（禁用 ATR 止损）以最大化训练期总收益，无视 MDD。这直接导致全网格 OOS MDD 从 24.81% 恶化至 32.66%。

**根本原因**：评分函数的 dd_score 梯度太平缓，无法给 IS 优化器足够强的惩罚信号。

#### 不足 B：排名函数 `_trend_strength_score` 未经验证

**位置**：`src/backtest/rotation.py`

**问题**：函数使用 `dk_value * (1.0 + run_len / 10.0)` 作为选股排名分，但：
1. `dk_value` 是 DK 指标的内部计算值，其与未来 1-2 周收益的 IC 从未被测量过
2. `run_len / 10.0` 的权重是拍脑袋决定的
3. 没有任何动量因子（如 RS 相对强度、N 日涨幅）
4. 没有波动率归一化（高波动标的在相同 dk_value 下风险更高）

#### 不足 C：等权分配忽略波动率差异

**位置**：`src/backtest/rotation.py`，第 412 行

```python
# 当前代码
allocation = (cash / (top_n - len(positions))) * 0.95
```

300750（年化波动率约 45%）和 601088（年化波动率约 25%）的仓位相同，导致波动率贡献严重不均衡。理论上 300750 应只分配约 55%（= 25%/(45%+25%)）的资金，而非 50%。

#### 不足 D：无行业集中约束

当前轮动池（300750、601857、601088）在特定市场环境下可能同时选入 601857（中国石油）和 601088（中国神华），造成能源行业集中。历史上中国能源股在原油价格下行时高度同向运动，集中持仓会放大尾部风险。

#### 不足 E：轮动元参数未经独立 WFO 验证

轮动框架的核心元参数——`top_n=2`、`rebalance_freq=10`（双周度）、3 只股票组合——是通过观察回测结果「后验选取」的，而非通过严格的训练/测试分离确定的。

对比：
- 单标的 WFO 的过拟合问题被充分识别
- 轮动框架中的同类问题尚未被识别和处理

#### 不足 F：eligibility 评分与 WFO 实际表现无相关性

修复 `_trend_quality_score` Bug 后，green 候选从 10 只扩展至 25 只，但新候选的 fast_grid 通过率仅 10%（1/10）。这说明 eligibility 评分的五个维度（rolling_sharpe、trend_quality、signal_freq、score_consistency、liquidity）与「该股票是否适合趋势跟踪 WFO」的相关性很低。**当前 eligibility 评分更像一个趋势存在性测试，而非趋势交易可盈利性测试。**

### 2.2 数据与信号层面的不足

#### 不足 G：仅依赖单一数据源（AkShare 日线）

当前所有信号都基于 AkShare 拉取的日线 OHLCV 数据：
- 无板块轮动信号（仅 515030 ETF 一个 sector exit 且已被证伪）
- 无资金流向数据（北向资金、融资融券）
- 无宏观因子（利率、PMI、汇率）
- 无期权/期货市场隐含信息

对于 300750（新能源）这类政策驱动股，纯技术信号在政策转向时无提前量。

#### 不足 H：回测期间的前向偏差未被完全排除

`eastmoney_dkbar` 参数（`p_fast=6, p_slow=12, p_signal=5`）是通过对历史数据观察后选定的，存在「参数选取偏差」。即使后续做了 WFO，初始参数域（param_grid 的范围）本身就是基于对全历史数据的了解设计的。

### P0-A：修复 IS 评分函数 MDD 惩罚不足（核心基础）

**问题根源**：`_composite_score()` 中的 `dd_score` 权重 15% 且梯度平缓，无法阻止 IS 优化器选择高风险参数。

**修复方案**：

```python
# src/backtest/wfo.py  _composite_score()

# 当前（有问题）
dd_score = max(0.0, 1.0 - res.max_drawdown * 2.0)

# 修复方案：引入非线性 MDD 惩罚 + 硬区间约束
if res.max_drawdown > 0.20:           # 超过 20% 直接大幅惩罚
    dd_score = max(0.0, (0.30 - res.max_drawdown) / 0.10)  # 20%→1.0, 30%→0.0
else:
    dd_score = max(0.0, 1.0 - res.max_drawdown * 3.5)      # 梯度增大：15%→0.48→比原来低
    
# 同时将 w_dd_score 从 0.15 提升到 0.25，相应降低 w_total_return 从 0.15 到 0.05
```

| 参数 | 当前值 | 建议值 |
|---|---|---|
| `w_calmar` | 0.35 | 0.30 |
| `w_sharpe` | 0.25 | 0.25 |
| `w_dd_score` | 0.15 | **0.25** |
| `w_total_return` | 0.15 | **0.10** |
| `w_trade_freq` | 0.10 | 0.10 |

**验收标准**：
- 对 300750 fast_grid（已知 atr_trailing_mult=1.5 胜出）重新运行，确认修复后 IS 优化器不再系统性地选择 `atr_trailing_mult=0` 或 `intrapos_dd_limit=0`
- 全网格 OOS 指标应不低于 fast_grid 的 80%（而非当前的 22%）

**时间估计**：30 分钟

### P0-B：轮动元参数 Walk-Forward 验证（消除隐性过拟合）

**目标**：验证 X1 中 `top_n=2`、`rebalance_freq=10`（双周度）、3 只股票的参数选择，不是对 2024-2026 测试期的过拟合。

#### B.1 方法论设计

采用「参数区间稳健性」验证，而非完整 WFO（避免用 2026 Q3-Q4 数据不足）：

对以下参数组合，分别在**四个独立子区间**回测，观察最优参数是否跨区间一致：

```
子区间 1：2018-01-01 ~ 2020-12-31（牛转熊转牛）
子区间 2：2020-01-01 ~ 2022-12-31（疫情到熊市）
子区间 3：2022-01-01 ~ 2024-06-30（熊转牛）
子区间 4：2024-07-01 ~ 2026-04-30（近期牛市）
```

测试的参数网格（共 24 组）：

```python
rotation_grid = {
    "top_n": [1, 2, 3],
    "rebalance_freq": [5, 10, 15],   # 周度、双周度、三周度
    "ranking_mode": ["trend_strength", "rs_momentum"],
}
```

新增 `scripts/run_rotation_grid.py`，支持对上述网格批量运行并输出各子区间最优参数对比表。

#### B.2 验收标准

| 判断依据 | 验收门槛 |
|---|---|
| 最优参数在 4 个子区间的一致性 | `top_n` 和 `rebalance_freq` 在至少 3/4 子区间中一致 |
| 当前参数（top_n=2, freq=10）的排名 | 在全部 4 个子区间中年化均排入前 1/3 |
| 参数退化幅度 | 使用排名第 5 的次优参数，全周期年化损失 ≤ 5% |

**如果验收不通过**：说明当前轮动参数存在显著回测偏差，需要重新选参并重新测试。

**时间估计**：2 小时（含脚本开发 1h + 运行 0.5h + 分析 0.5h）

### P1-A：系统寻找第二个强 alpha 标的

**目标**：找到至少一只与 300750 行业不相关、具备独立 alpha 的标的，使轮动池不再完全依赖单只股票。

#### A.1 Alpha 强度的重新定义

当前 eligibility 评分测量「趋势性」，但与「趋势跟踪盈利能力」相关性低。需要直接测量**信号-收益相关性**（IC）作为 alpha 强度代理指标：

**新增 alpha_ic_screen.py 脚本**，对任意股票计算：
1. **信号 IC**：每次 BUY 信号后 N 日（N=10,20,30）的前向收益，与 DK 指标值的 Spearman 相关系数
2. **趋势跟踪超额收益**：简单趋势策略（固定参数，无优化）相对 buy-hold 的超额年化
3. **回撤条件收益**：牛市段和熊市段分别统计（用沪深 300 指数的 MA200 状态划分）

#### A.2 目标标的选择范围

基于已有 eligibility 扩展池（44 只），重点排查**与 300750 行业相关性 < 0.5 的 green 候选**：

| 行业 | 候选标的 | 理由 |
|---|---|---|
| 白酒消费 | 000858 五粮液（81.4 分）、600809 山西汾酒（85.3 分）、000568 泸州老窖 | 与新能源不相关，慢牛趋势 |
| 医药 | 603259 药明康德（85.3 分） | fast_grid 结果 9.7%（MDD 过高，但 IC 可能好） |
| 证券 | 600030 中信证券（85.6 分） | 行业 alpha，与市场高度同向 |
| 消费制造 | 002594 比亚迪（74.1 分） | 新能源汽车，与 300750 相关但独立 alpha |
| 公用事业 | 600900 长江电力 | 稳定慢牛，低波动 |

#### A.3 快速筛选流程

**Step 1**（每只约 10 分钟）：运行 `alpha_ic_screen.py`，筛选出信号 IC（20 日前向）> 0.03（有统计意义）且牛市/熊市超额均为正的标的。

**Step 2**（通过 Step 1 的标的，约 15 分钟/只）：运行 `run_rotation.py` 用「2 只轮换（300750 + 候选）」的简化轮动，测试 2018-2026 年化。

**Step 3**（通过 Step 2 的标的）：运行完整 4 子区间稳健性测试。

#### A.4 验收标准

找到至少 1 只标的，满足：
- 加入后「300750 贡献度」（即去除该标的导致的年化下降）降至 ≤ 10 个百分点（当前 15 个百分点）
- 单独与 300750 的 Pearson 滚动 60 日相关性均值 < 0.60
- 加入后全周期 Calmar ≥ 1.20（不倒退）

**时间估计**：4 小时

### P1-B：改进轮动排名函数（IC 导向替代启发式）

**目标**：用经过 IC 验证的多因子排名替代当前的 `dk_value * (1 + run_len/10)` 启发式。

#### B.1 候选排名因子

| 因子 | 计算方式 | 预期 IC 方向 | 经济逻辑 |
|---|---|---|---|
| `dk_value` | DK 指标当前值 | + | 趋势强度 |
| `run_len_norm` | `dk_run_len / 20`，cap 在 1.0 | + | 趋势持续性 |
| `rs_20` | 相对沪深 300 的 20 日超额收益 | + | 相对动量 |
| `rs_60` | 相对沪深 300 的 60 日超额收益 | + | 中期动量（与 rs_20 互补） |
| `vol_adj` | `1 / (20日ATR / close * 100)`，波动率倒数 | + | 低波动溢价 |
| `above_ma120` | 二元：收盘价是否高于 MA120 | + | 趋势方向确认 |

#### B.2 因子 IC 测量

**新增 `scripts/measure_ranking_ic.py`**，对轮动池的每只股票计算各因子的历史 IC：
- 每次 BUY 信号当日计算因子值，关联后续 10/20/30 日收益
- 输出 IC 均值（ICIR = IC 均值 / IC 标准差，越高越好）

**预期结论**：
- `rs_60` 的 ICIR 可能高于 `dk_value`（A 股动量效应 6-12 个月较强）
- 组合使用比单一因子 IC 更高（经典多因子降噪效果）

#### B.3 实现方案

**改进后的排名函数框架**：

```python
def _multi_factor_score(
    trend: pd.DataFrame,
    ohlcv: pd.DataFrame,
    idx: int,
    *,
    index_returns: pd.Series | None = None,
    w_trend: float = 0.40,     # IC 验证后调整
    w_rs_momentum: float = 0.35,
    w_vol_adj: float = 0.25,
) -> float:
    """IC-weighted multi-factor ranking score."""
    # 需返回 -1.0 if bearish（与当前接口兼容）
    ...
```

权重 `w_trend`, `w_rs_momentum`, `w_vol_adj` 通过 IC 分析确定后固定——**不做优化**，避免过拟合。

#### B.4 验收标准

- 新排名函数在 3 个非重叠子区间中，因子 ICIR > 0（至少有统计意义的正预测力）
- 在 2018-2026 全周期，使用新排名函数的轮动年化 ≥ 原排名函数的 95%（改进排名不应以牺牲历史表现为代价）
- 2022-2024 熊市测试期表现提升（熊市中动量因子的保护作用应更明显）

**时间估计**：3 小时

### P2-A：波动率加权仓位管理

**目标**：将等权分配替换为波动率反比加权，降低高波动标的（如 300750）的资金集中度。

#### A.1 实现方案（最小改动）

在 `src/backtest/rotation.py` 的 `run_rotation_backtest()` 中，在每次 rebalance 时计算各持仓标的的 20 日实现波动率，并按反比加权：

```python
# 计算波动率加权
vols = {}
for sym in target:
    df = aligned[sym]
    ret = df["close"].pct_change().iloc[max(0, i-20):i]
    vols[sym] = float(ret.std() * np.sqrt(252)) + 1e-6  # 年化，防零

# 反比加权（+ clamp 防止单标的权重过于极端）
raw_weights = {sym: 1.0 / vols[sym] for sym in target}
total = sum(raw_weights.values())
weights = {sym: min(max(raw_weights[sym] / total, 0.30), 0.70) for sym in target}
# clamp 范围：单标的最低 30%，最高 70%
```

新增参数：`position_sizing: str = "equal" | "vol_inverse"`，默认保持 `equal` 以兼容当前配置，新配置选项启用 `vol_inverse`。

#### A.2 验收标准

- 在 2022-2024 熊市测试期：MDD 应低于等权版本 ≥ 2%（波动率加权的主要收益在熊市）
- 在 2024-2026 测试期：年化损失 ≤ 3%（可接受的收益-风险权衡）

### P2-B：行业集中约束

**目标**：防止轮动框架同时持有高度相关的同行业标的。

#### B.1 行业映射表

新增 `configs/sector_map.yaml`，为轮动池所有标的配置行业标签：

```yaml
sectors:
  新能源: ["300750"]
  能源: ["601857", "601088"]
  白酒: ["000858", "600809", "000568"]
  银行: ["600036", "601166", "600030"]
  医药: ["603259"]
  汽车: ["002594"]
```

#### B.2 约束逻辑

在 `run_rotation_backtest()` 的轮换决策中，加入「同一行业最多持有 1 只」约束：

```python
# 选出 top_n 标的后，检查行业集中
def _apply_sector_constraint(target: set[str], sector_map: dict) -> set[str]:
    seen_sectors: set[str] = set()
    final: list[str] = []
    for sym in sorted_by_score:
        sector = sector_map.get(sym, sym)  # 无映射则以自身为行业
        if sector not in seen_sectors:
            seen_sectors.add(sector)
            final.append(sym)
        if len(final) == top_n:
            break
    return set(final)
```

#### B.3 验收标准

- 601857（石油）和 601088（神华）在 2022-2024 能源牛市中应被正常选入（不同行业优先级都高时可以共存），在能源集体转弱时约束应能阻止\"强迫持仓\"
- 加入约束后，全周期年化损失 ≤ 1.5%（轮动池足够大时，行业约束成本低）

**前提条件**：P1-A 完成后轮动池扩充到 ≥ 5 只，否则行业约束会造成仓位空置。

**时间估计**：1 小时
